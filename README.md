# VS Code Landing Page Recreation

A front-end recreation of the official Visual Studio Code landing page, built from scratch using HTML and CSS.

This project is part of my journey into web development, with a focus on learning by building rather than relying on copy-paste solutions.

## ✨ Features

- Dark-themed layout inspired by the official VS Code website
- Custom navigation bar and dropdown menu
- Hero section with download button
- Background image with a gradient overlay
- Feature section with text and visuals
- Custom styling using CSS Flexbox, spacing, and typography

## 🛠️ Built With

- **HTML5** for page structure
- **CSS3** for styling, layout, and visual effects
- **VS Code** as the development environment

## 🎯 Project Goals

- Strengthen my understanding of HTML and CSS fundamentals
- Practice recreating real-world website layouts
- Improve my understanding of Flexbox, backgrounds, typography, and positioning
- Build independently and understand the code behind every element

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `vs.html` in your browser, or use the Live Server extension.

This project is a work in progress. More sections, styling improvements, and responsive design adjustments may be added as I continue learning.
